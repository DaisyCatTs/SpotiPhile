Use `../refinement-comparison.html` for page/theme/size and Before/After selectors.

1280x800, light 760x800, OLED 1440x900.

Before captures are the rejected 25:2-era proposal, saved before this revision.
They came from the shared T3 preview, which may scale output. After captures
use installed headless Chromium at the exact filename viewport, device scale 1,
with animations disabled. Compare composition and styling, not sharpness.

playlist collage reuse the documented local assets. These are review artifacts,
not an approved design, native application screenshots or performance evidence.
