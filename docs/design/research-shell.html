Research, tokens and boundaries

Research basis

This direction combines album identity, dense tables, optional side panels and theme ownership from the audited desktop music references.

  • Roon Albums and Signal Path
  • Apple Music column browser
  • Audirvana Studio 3.0
  • Spotify desktop redesign notes
  • foobar2000 screenshots and MusicBee skins

Boundaries

The data is fictional review content. It does not rename the app to Spotiphile, add new audio formats, implement Pure Shuffle, or change Spotify playback capabilities.

Native fit

The shell maps to existing Rust boundaries: UI emits Actions, the player bar stays persistent, Queue and Lyrics remain optional, and Winamp/MilkDrop entry points stay visible.
